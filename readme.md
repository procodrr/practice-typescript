# TypeScript Questions From Basics to Advance

This repository contains TypeScript questions and notes ranging from beginner to advanced level. The topics are arranged in a structured order, so it is recommended to follow them sequentially. Along the way, you'll learn not only TypeScript concepts but also gain insights into JavaScript, tooling, compiler behavior, language design decisions, and other foundational topics that help build a deeper understanding of the TypeScript ecosystem.

---

You can follow the videos in parallel and test yourself using the questions available in the repository, which are organized according to the course structure. Similar sections may be combined if they are closely related.

If you notice that a section is skipped (for example, from 2.4 to 2.6), it usually means that the skipped section is either a practical video that you are expected to perform, or it contains additional information meant only for awareness.

We are trying to keep the content as focused on questions as possible.
